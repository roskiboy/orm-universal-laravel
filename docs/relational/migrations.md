# Migrations

The DDL engine lives in `OrmUniversal\Relational\Migration`. It compiles dialect
operations into one or more `CompiledQuery` objects; **it never executes anything by itself**.

## SchemaOperation

Immutable, dialect-independent operation:

```php
use OrmUniversal\Relational\Migration\SchemaOperation;

SchemaOperation::createTable($tableDefinition, ifNotExists: true);
SchemaOperation::dropTable('orders', ifExists: true);
SchemaOperation::addColumns('orders', [$columnDefinition]);
SchemaOperation::dropColumns('orders', ['legacy_total']);
SchemaOperation::addIndex('orders', $indexDefinition);
SchemaOperation::dropIndex('orders', 'orders_customer_idx');
SchemaOperation::addForeignKey('orders', $foreignKeyDefinition);
SchemaOperation::dropForeignKey('orders', 'orders_customer_fk');
SchemaOperation::renameTable('orders', 'sales_orders');
SchemaOperation::truncateTable('orders');
```

`operationName()` returns `create_table`, `drop_table`, `add_columns`,
`drop_columns`, `add_index`, `drop_index`, `add_foreign_key`,
`drop_foreign_key`, `rename_table` or `truncate_table`; `payload()` exposes the
arguments.

## Real definitions

```php
use OrmUniversal\Contracts\Enums\TypeKind;
use OrmUniversal\Contracts\ValueObjects\ColumnDefinition;
use OrmUniversal\Contracts\ValueObjects\ForeignKeyDefinition;
use OrmUniversal\Contracts\ValueObjects\IndexDefinition;
use OrmUniversal\Contracts\ValueObjects\TableDefinition;

$table = new TableDefinition(
    name: 'orders',
    columns: [
        new ColumnDefinition(name: 'id', databaseType: 'bigint', kind: TypeKind::BigInteger, nullable: false, autoIncrement: true),
        new ColumnDefinition(name: 'customer_id', databaseType: 'bigint', kind: TypeKind::BigInteger, nullable: false),
        new ColumnDefinition(name: 'total', databaseType: 'decimal(12,2)', kind: TypeKind::Decimal, nullable: false, default: 0),
        new ColumnDefinition(name: 'active', databaseType: 'boolean', kind: TypeKind::Boolean, nullable: false, default: true),
    ],
    indexes: [new IndexDefinition(name: 'orders_customer_idx', columns: ['customer_id'])],
    foreignKeys: [
        new ForeignKeyDefinition(name: 'orders_customer_fk', columns: ['customer_id'], foreignTable: 'customers', foreignColumns: ['id'], onDelete: 'cascade'),
    ],
    options: ['primary' => ['id'], 'engine' => 'InnoDB', 'charset' => 'utf8mb4'],
);
```

`ColumnDefinition` supports `unsigned`, `length`, `precision`, `scale`,
`comment`, `generatedExpression`, `generatedStored` and `constraint`.
`IndexDefinition` supports `unique`, `primary`, `type`, `where` (partial),
`algorithm` and `using` (GIN, GiST, BRIN...).

## Compile

```php
use OrmUniversal\Relational\Dialect\PostgreSqlDialect;
use OrmUniversal\Relational\Migration\Compiler;
use OrmUniversal\Relational\Migration\SchemaBuilder;

$dialect = PostgreSqlDialect::make('18.0');

/** @var Compiler $compiler */
$compiler = $dialect->migrationCompiler();
$statements = $compiler->compile(SchemaOperation::createTable($table));
$compiler->supports($operation); // false for unsupported operations

foreach ($statements as $compiled) {
    echo $compiled->sql; // CREATE TABLE + CREATE INDEX
}
```

`Compiler::createTable()` returns the complete list (table + non-primary indexes).
`Compiler::columnDefinition()` renders a column and
`supports()` answers per operation; on SQLite it rejects `add_foreign_key` on an
existing table.

## SchemaBuilder

Facade that compiles without executing:

```php
$builder = new SchemaBuilder($dialect);
$builder->create($table, ifNotExists: true);   // list<CompiledQuery>
$builder->dropIfExists('orders');
$builder->rename('orders', 'sales_orders');
$builder->truncate('orders');
$builder->compile(SchemaOperation::addIndex('orders', $index));
```

## DDL per dialect

- **MySQL/MariaDB**: `auto_increment`, `unsigned`, `engine`/`charset` in
  `create table`, `drop index tabla.indice`, partial index rejected with
  `MigrationException`.
- **PostgreSQL**: `generated by default as identity`, `using gin/gist/brin`,
  partial indexes with `where`.
- **SQLite**: `supports()` is limited to create/drop/rename/add/drop columns and
  indexes; it cannot add an FK to an existing table.
- **SQL Server**: `identity(1,1)`, `drop constraint` for FKs,
  `drop index indice on tabla`.
- **Oracle**: `generated by default on null as identity`, `alter table ...
  rename to`, `drop constraint`; auto-commit DDL.

Column defaults: booleans use the dialect's `booleanLiteral()`; numbers are
emitted without quotes; `current_timestamp`, `current_date`, `current_time`,
`nextval(...)` and parenthesized expressions are preserved; the rest is quoted with
`escapeStringLiteral()`.

## Security and execution

`SchemaBuilder`/`Compiler` do not execute. The runner decides the policy: drop,
truncate and destructive alterations should be explicitly confirmed. See
[Security](security.md) and [Schema](schema.md).

Schema snapshots and diff without touching the database: [Schema](schema.md). Multi-dialect DDL
golden tests: [Testing](testing.md).
